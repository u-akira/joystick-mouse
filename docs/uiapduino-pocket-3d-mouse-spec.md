| 項目 | 内容 |

この文書では、元プロジェクトのArduino MicroをUIAPduino Pro Micro CH32V003 V1.4へ置き換えるための、現時点の部品・配線・操作仕様を定義する。

### v0.3の更新内容

- I2C接続SSD1306 OLEDを参考構成として追加
- UIAPduinoの標準`Wire`設定をSDA=D3、SCL=D4として記載
- OLED追加時の入力ピン案を外付けタクト=D5、KY-023 SW=D7として記載
- Wokwi用のOLED参考図・スケッチへのリンクを追加

## 2. 目的

右手で通常のマウスを操作しながら、左手のジョイスティックでFusion 360のビューポートを操作できる小型コントローラーを作る。

通常のマウスカーソルを動かすための装置ではなく、Fusion 360のパンとオービットを補助する専用入力デバイスとする。

## 3. 使用部品

### 3.1 確定部品

- UIAPduino Pro Micro CH32V003 V1.4
- KY-023 Dual-axis Joystickモジュール
- 6×6×5 mm、2ピンDIP、モーメンタリ・タクトスイッチ
- USBケーブル
- 3Dプリント筐体

### 3.2 現時点で操作に使わない機能

- KY-023に搭載されている押し込みスイッチ（SW端子）
  - D7へ配線して予備入力として確保する
  - 現時点のパン・オービット操作には使用しない
- 無線通信
- ジョイスティックによる通常のカーソル移動
- ジョイスティック押し込みによるクリック

## 4. 操作仕様

| 入力 | 動作 |
|---|---|
| ジョイスティックを左右・上下に倒す | Fusion 360の視点操作 |
| タクトスイッチを押さずにジョイスティックを倒す | パン（中ボタン相当） |
| タクトスイッチを押しながらジョイスティックを倒す | オービット（Shift + 中ボタン相当） |
| ジョイスティックが中央 | マウス操作を発生させない |
| 右手の通常マウスのホイール | ズーム |

タクトスイッチを押しているかどうかで、パンとオービットを切り替える。

## 5. 電気仕様・配線

UIAPduinoの電源設定は、まず5 V設定を前提とする。3.3 V設定で使用する場合は、KY-023の電源も3.3 Vへ変更し、アナログ入力範囲を確認する。

### 5.1 KY-023

| KY-023端子 | UIAPduino接続先 | 用途 |
|---|---|---|
| GND | GND | グランド |
| +5V | 5V | モジュール電源 |
| VRX | A0 | X軸アナログ入力 |
| VRY | A1 | Y軸アナログ入力 |
| SW | D7 | 予備入力。現時点では操作に使用しない |

### 5.2 外付けタクトスイッチ

| タクトスイッチ端子 | UIAPduino接続先 |
|---|---|
| 端子1 | D5 |
| 端子2 | GND |

ソフトウェアではD5を`INPUT_PULLUP`として使用する。スイッチを押していないときはHIGH、押しているときはLOWとして扱う。

2ピンタクトスイッチには極性がない。ただし、同じ側にある端子同士ではなく、スイッチ内部の接点をまたぐ2端子を使用する。

### 5.3 ピン使用方針

- A0：ジョイスティックX軸
- A1：ジョイスティックY軸
- D5：外付けタクトスイッチ
- D7：KY-023押し込みスイッチの予備入力
- D2：基板LEDとの競合を避けるため使用しない
- D11：デバッグ・書き込み用途との競合を避けるため使用しない

## 6. ファームウェア仕様

### 6.1 入力処理

- 起動時にジョイスティックの中央値を取得する
- D7を`INPUT_PULLUP`として初期化する
- KY-023押し込みスイッチは読み取り可能にするが、現時点では操作へ反映しない
- X軸・Y軸それぞれに不感帯を設ける
- 中央値からの距離に応じてマウス移動量を計算する
- X軸・Y軸の反転設定を持たせる
- 感度を調整可能にする
- タクトスイッチのチャタリングを除去する

初期値として、ジョイスティック中央付近の約10〜15 %を不感帯とする。

### 6.2 HID処理

- USB HIDマウスとしてマウス移動を送信する
- USB HIDキーボードとしてShiftキーを送信する
- パン時は中ボタンを押しながら移動する
- オービット時はShiftキーと中ボタンを押しながら移動する
- ジョイスティックが不感帯に戻ったら、押下中のHIDボタンを解放する
- USBリセット・切断時には、マウスボタンとShiftキーを解放する

### 6.3 HID実装の確認事項

UIAPduinoへの書き込み自体はArduino IDEおよびArduino CLIで成功している。ただし、CH32V003向けの標準Arduino環境で`Mouse`および`Keyboard`がそのまま使用できるかは、別途確認が必要である。

必要に応じて、UIAPduino CH32V003向けのHIDパッケージを採用し、Keyboard + Mouseモードで検証する。

### 6.4 OLED表示（参考構成）

OLEDは基本仕様には含めず、将来追加できる参考機能とする。

I2C接続のSSD1306 OLEDを使用する場合、UIAPduinoのArduinoコアにおける標準`Wire`設定は以下のとおりである。

| OLED信号 | UIAPduino |
|---|---|
| SDA | D3 / PC1 |
| SCL | D4 / PC2 |
| VCC | 電源設定に合わせる |
| GND | GND |

以前のESP32設定である`GPIO21=SDA`、`GPIO22=SCL`はUIAPduinoへそのまま移植しない。

OLEDを追加する場合は、D3/D4をI2Cに空ける必要があるため、入力ピンを次のように変更する案を採用する。

- 外付けタクトスイッチ：D5
- KY-023押し込みスイッチ：D7

この場合、D7はSPIのSCKとも兼用だが、I2C OLEDを使用する構成ではSPIを使わないため、GPIO入力として使用できる。

WokwiのArduino NanoではI2CピンがA4/A5になるため、実機のD3/D4とは別に見える。WokwiではOLED参考構成を別の`diagram.oled-reference.json`として管理する。

## 7. 筐体仕様

### 7.1 基本方針

- 元プロジェクトの小型左手コントローラー形状をベースにする
- 親指でKY-023を操作する
- タクトスイッチは親指または人差し指で押せる位置に配置する
- USB-C端子へ外部からアクセスできる開口部を設ける
- UIAPduinoの基板外形、USB-C位置、部品高さに合わせて基板ポケットを作り直す

### 7.2 重量目標

元プロジェクトの約48 gを目標値とする。ただし、UIAPduino基板、KY-023、タクトスイッチ、配線、筐体材料が異なるため、最終重量は実測して確定する。

### 7.3 未確定の機械寸法

- KY-023の筐体内での固定方法
- UIAPduinoの固定穴・基板ポケット
- USB-C開口部の位置と寸法
- タクトスイッチの押下位置
- ケーブルの引き回し
- 3Dプリント時のクリアランス

## 8. 開発・書き込み環境

### 8.1 現在確認済み

- WindowsでUIAPduino Pro Micro CH32V003 V1.4を認識できる
- Arduino IDE経由の書き込みに成功している
- Arduino CLI経由のサンプルスケッチ書き込みに成功している
- ブートローダー検出後に`Image written.`まで到達している

### 8.2 現在の書き込み対象

現在は以下のボード設定で書き込みを行っている。

```text
UIAP:ch32v:CH32V00x_EVT:pnum=CH32V003V1DOT4,upload_method=minichlink
```

HID対応パッケージを採用する場合は、ボードパッケージとFQBNが変わる可能性があるため、HIDテスト時に再確認する。

## 9. 受け入れ条件

最初の実機版は、以下を満たすことを目標とする。

1. WindowsがUSB HIDマウス・キーボードとして認識する
2. ジョイスティック中央でカーソルや視点が勝手に動かない
3. ジョイスティック単独の操作でパンできる
4. タクトスイッチを押しながら操作するとオービットできる
5. スイッチを離すと中ボタンとShiftキーが確実に解放される
6. X軸・Y軸の向きが自然である
7. 右手の通常マウスと同時に使用できる
8. USB再接続後もボタン押下状態が残らない
9. 連続操作中に意図しないクリックや視点移動が発生しない
