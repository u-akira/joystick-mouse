# UIAPduino版 Pocket 3D Mouse 作業手順書

## 1. 目的

KY-023ジョイスティックと2ピンタクトスイッチを使い、UIAPduino Pro Micro CH32V003 V1.4でFusion 360のパン・オービット操作を実現する。

仕様の詳細は、以下のドキュメントを参照する。

- [UIAPduino版 Pocket 3D Mouse 仕様書](./uiapduino-pocket-3d-mouse-spec.md)

### 2026-10-28更新

- I2C SSD1306 OLEDを任意の参考構成として追加
- OLED追加時はSDA=D3、SCL=D4を使用
- OLED構成では外付けタクトをD5、KY-023押し込みをD7へ移動
- Wokwi用のOLED参考図と確認スケッチを追加

## 4. Phase 0：部品と資料の確認

### 作業

1. UIAPduino Pro Micro CH32V003 V1.4を確認する
2. KY-023の端子名を確認する
3. 6×6×5 mm、2ピンタクトスイッチの端子を確認する
4. USBケーブル、ジャンパ線、ブレッドボードを用意する
5. KY-023の実寸を測定する
6. UIAPduinoの基板外形、USB-C位置、固定方法を確認する

### 確認結果

- KY-023：`GND / +5V / VRX / VRY / SW`
- タクトスイッチ：D5とGNDへ接続
- KY-023の`SW`：D7とGNDへ接続し、予備入力として確保
- 電源設定：まずUIAPduinoを5 V設定で使用

### 完了条件

- 部品の端子を間違いなく識別できる
- 筐体設計に必要な外形寸法を記録できる

## 5. Phase 1：配線と電源確認

### 配線

| 部品 | UIAPduino |
|---|---|
| KY-023 GND | GND |
| KY-023 +5V | 5V |
| KY-023 VRX | A0 |
| KY-023 VRY | A1 |
| KY-023 SW | D7 |
| タクトスイッチ端子1 | D5 |
| タクトスイッチ端子2 | GND |

### 手順

1. USBを抜いた状態で配線する
2. タクトスイッチの同じ側の端子を選んでいないことを確認する
3. 5 VとGNDが短絡していないことを確認する
4. KY-023の`SW`端子がD7へ接続されていることを確認する
5. UIAPduinoを5 V設定にする
6. USBを接続する
7. 部品の発熱、異臭、異常なLED状態がないか確認する

### 完了条件

- 電源投入直後に異常な発熱がない
- 5 VとGNDの短絡がない
- 配線表と実配線が一致している

## 6. Phase 2：タクトスイッチ入力テスト

### 目的

D5に接続した外付けタクトスイッチが、押下時LOW、解放時HIGHとして安定して読めることを確認する。

### 実装内容

- D5を`INPUT_PULLUP`に設定する
- 押下状態を検出する
- チャタリング除去は後のHID実装前に追加する
- まずはLEDの点灯・消灯で状態を確認する

### 確認項目

- 押していないときにLEDが消灯する
- 押している間だけLEDが点灯する
- 軽く触れただけで状態が不安定にならない
- スイッチを離したあとに押下状態が残らない

### 完了条件

- 20回以上の押下で誤検出がない
- 押下状態と解放状態を正しく判定できる

## OLED参考構成（任意）

OLEDは基本構成には含めず、必要になった場合に追加する。

### I2C OLEDの配線

UIAPduinoのArduinoコアの標準`Wire`設定では、I2C OLEDのSDA/SCLはD3/D4を使用する。

```text
OLED SDA ── UIAPduino D3
OLED SCL ── UIAPduino D4
```

このため、OLEDを追加する場合は、入力ピンを次のように移動する。

| 用途 | OLED追加時のピン |
|---|---|
| 外付けタクトスイッチ | D5 |
| KY-023押し込みスイッチ | D7 |

WokwiにはOLED参考構成を別図として追加している。主配線図も外付けタクト=D5、KY-023 SW=D7へ更新している。

- [OLED参考配線図](../wokwi/phase1-wiring/diagram.oled-reference.json)
- [OLED参考スケッチ](../wokwi/phase1-wiring/sketch.oled-reference.ino)

## 7. Phase 3：ジョイスティック入力テスト

### 目的

KY-023のVRX・VRYを読み取り、中央値、操作方向、軸の反転要否を確認する。

### 実装内容

- A0からX軸を読む
- A1からY軸を読む
- 起動時の中央値を取得する
- 中央値との差分を計算する
- 中央付近の不感帯を設定する

### 値の確認方法

UIAPduinoの環境ではシリアルポートを前提にしない。まずは以下のいずれかで確認する。

1. 値の範囲ごとに基板LEDの点滅速度を変える
2. HID実装後にWebHID等で値を表示する
3. 必要に応じてテスト用の別のUSB出力方法を用意する

### 確認項目

- 何も触らない状態でX/Yが中央付近になる
- X軸を倒したとき、A0の値が変化する
- Y軸を倒したとき、A1の値が変化する
- 軸ごとに最大・最小方向を確認する
- 中央に戻したとき、値が中央付近へ戻る
- ジョイスティックを離した状態で値が大きく揺れない

### 完了条件

- X/Y軸の方向を記録できる
- 中央値と不感帯の初期値を決められる
- ソフトウェアで軸反転が必要か判断できる

### 7.1 ジョイスティック押し込みスイッチの予備入力確認

KY-023の`SW`端子はD7へ接続する。現時点ではパン・オービットの操作には使用しないが、将来のクリックやモード切替に使えるよう、入力だけ確認する。

#### 実装内容

- D7を`INPUT_PULLUP`に設定する
- 押していないときはHIGHとして読む
- ジョイスティックを押し込んだときはLOWとして読む
- 現時点ではHID操作を発生させない

#### 完了条件

- ジョイスティックを押し込んでいないときにRELEASEDになる
- ジョイスティックを押し込んだときにPRESSEDになる
- X/Y軸の操作に影響しない

## 8. Phase 4：HID互換性テスト

### 目的

CH32V003でマウス移動、中ボタン、ShiftキーをUSB HIDとして送信できることを確認する。

### 手順

1. 最小のMouseテストを作成する
2. WindowsがUSB HIDマウスとして認識することを確認する
3. 一定量のマウス移動を送信する
4. 中ボタンの押下・解放を送信する
5. Shiftキーの押下・解放を送信する
6. USB再接続後にボタン押下状態が残らないことを確認する

### パッケージ方針

まず現在のUIAPduino環境で`Mouse`と`Keyboard`が利用できるか確認する。コンパイルまたは認識に問題がある場合は、UIAPduino CH32V003向けのHIDパッケージを使用し、Keyboard + Mouseモードで再試験する。

### 完了条件

- Windowsがマウス・キーボードHIDとして認識する
- マウス移動が1回だけ送信される
- 中ボタンとShiftキーの押下・解放が正しく動作する
- リセット・切断時にキーやボタンが押しっぱなしにならない

## 9. Phase 5：パン操作の実装

### 操作

タクトスイッチを押さずにジョイスティックを倒すと、ジョイスティックの方向に応じて中ボタンを押しながらマウス移動を送信する。

### 実装順序

1. ジョイスティックが不感帯外か判定する
2. 不感帯外なら中ボタンを押す
3. X/Y差分をマウス移動量へ変換する
4. ジョイスティックが不感帯へ戻ったら中ボタンを離す
5. 感度を定数または設定値として調整可能にする

### 完了条件

- ジョイスティックを倒した方向へFusion 360の視点をパンできる
- 中央付近で視点が動かない
- ジョイスティックを戻すと中ボタンが解放される

## 10. Phase 6：オービット操作の実装

### 操作

タクトスイッチを押しながらジョイスティックを倒すと、Shiftキーと中ボタンを押しながらマウス移動を送信する。

### 実装順序

1. タクトスイッチの状態を取得する
2. スイッチ押下中かつジョイスティックが不感帯外か判定する
3. Shiftキーを押す
4. 中ボタンを押す
5. X/Y差分をマウス移動量へ変換する
6. ジョイスティックが中央へ戻ったら中ボタンとShiftキーを解放する
7. スイッチを離したときも、必ず中ボタンとShiftキーを解放する

### 完了条件

- タクトスイッチを押しながら操作するとオービットできる
- タクトスイッチを離した瞬間にShiftと中ボタンが解放される
- スイッチのチャタリングでパンとオービットが頻繁に切り替わらない

## 11. Phase 7：Fusion 360での調整

### 調整項目

- X軸の左右方向
- Y軸の上下方向
- パンの感度
- オービットの感度
- 中央不感帯
- 最大移動量
- スイッチの押しやすさ

### 調整手順

1. Fusion 360で簡単なモデルを開く
2. パンだけを確認する
3. オービットだけを確認する
4. X/Yの反転を確認する
5. 感度を低い値から上げる
6. 長時間操作して疲れや誤操作を確認する

### 完了条件

- 右手マウスの操作を邪魔せずに視点操作できる
- 視点操作が意図せず発生しない
- 短時間の操作でジョイスティックやスイッチに無理な力がかからない

## 12. Phase 8：筐体設計

### 手順

1. KY-023の外形と固定穴を測定する
2. UIAPduinoの基板外形とUSB-C位置を測定する
3. タクトスイッチの押下位置を決める
4. 元プロジェクトの筐体を流用できるか確認する
5. 必要なら基板ポケットとUSB-C開口部を設計し直す
6. 配線の逃げ、基板固定、ジョイスティック固定を追加する
7. 試作筐体を印刷する

### 設計上の注意

- USB-Cを抜き差しできる空間を確保する
- KY-023のレバーが筐体に干渉しないようにする
- タクトスイッチを強く押したときに基板や配線へ力が集中しないようにする
- 基板裏面の端子やはんだ部が筐体に接触しないようにする
- 分解・再配線できるようにする

### 完了条件

- 基板とジョイスティックを固定できる
- USBケーブルを接続できる
- すべての操作が筐体装着後も同じように動作する
- 目標重量を実測できる

## 13. Phase 9：最終試験

### 電気・ソフトウェア試験

- [ ] WindowsがHIDデバイスとして認識する
- [ ] 起動時の中央値取得が安定する
- [ ] 中央位置で視点が動かない
- [ ] X/Y方向が正しい
- [ ] パンが動作する
- [ ] オービットが動作する
- [ ] スイッチを離すとボタンが解放される
- [ ] USB再接続後も正常に動作する
- [ ] 30分以上の連続操作で異常がない

### 機械試験

- [ ] ジョイスティックがぐらつかない
- [ ] タクトスイッチが筐体内で回転しない
- [ ] USB-C端子に無理な力がかからない
- [ ] 配線が可動部に挟まらない
- [ ] 筐体を持ったときに操作しやすい
- [ ] 重量を測定して記録する

## 14. 作業上のリスクと対策

| リスク | 対策 |
|---|---|
| 5 VとGNDの短絡 | USB接続前に配線と導通を確認する |
| KY-023の軸方向が想定と逆 | 軸方向を記録し、ソフトウェアで反転する |
| 中央値の揺れ | 起動時キャリブレーションと不感帯を使用する |
| タクトスイッチのチャタリング | デバウンス処理を実装する |
| HIDライブラリ非対応 | 最小HIDテスト後、UIAP_HIDパッケージを検討する |
| ボタン押しっぱなし | リセット・切断・スイッチ解放時に強制解放する |
| 筐体内の干渉 | 基板・ジョイスティック・USB-Cの実測後に設計する |
